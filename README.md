# Awesome Chocolates – Sales Data Analysis Using Power BI

## Project Overview

This project focuses on analyzing the sales and shipment data of Awesome Chocolates using Microsoft Power BI.

The dataset contains information related to sales persons, sales performance, countries, geographical sales, shipments, shipment IDs, and total shipments.

The main objective of this project is to analyze the available data, identify important patterns and trends, and present meaningful insights through data visualization.

## Objectives

- Analyze sales performance across different countries and regions.
- Understand the performance of different sales persons.
- Analyze shipment details and total shipments.
- Identify important sales trends and patterns.
- Create meaningful visualizations using Power BI.
- Present the analyzed results in a clear and understandable format.

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- Figma

## Data Analysis Process

1. The dataset was collected in Excel format.
2. The data was cleaned and prepared for analysis.
3. The cleaned data was imported into Power BI.
4. Different sales and shipment-related aspects were analyzed.
5. Visualizations and charts were created to understand the data.
6. The analysis and visualizations were organized into a report using Figma.
7. The final analysis report was captured and presented as a single image.

## Data Analysis

The analysis focuses on:

- Sales performance
- Sales persons
- Country-wise sales
- Geographical sales analysis
- Shipment details
- Shipment IDs
- Total shipments
- Sales trends and patterns
